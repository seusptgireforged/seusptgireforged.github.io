New & Key Features

The SEUS atmosphere, refined.

Reforged keeps the original shader as its foundation while bringing next-generation visual upgrades and performance controls.

Water & Surfaces

Improved screen space reflections

Significantly upgraded screen space reflections designed to make water surfaces and wet blocks look remarkably clear, realistic, and lively.

Ray Traced Lighting

Native emission support for Glow Berries, Glow Lichen, Amethyst Buds and more

Full ray-traced lighting support built natively into blocks like Glow Berries, Lichen, and Amethyst Buds so they naturally cast real, glowing light onto nearby walls and floors.

Dynamic Shadows

Ray Traced player shadows

Experience authentic, path-traced player shadows that dynamically cast across the environment whenever you stand in front of any light source.

Enhanced Visuals

Refined reflections, lighting, clouds, and atmospheric effects for a richer in-game image.

More Control

Additional shader-menu options let you tailor visual effects to your own preferences.

Performance Focus

Targeted optimizations and adjustable settings help balance image quality with frame rate.

Cloud Choices

Switch between the Reforged cloud mode and Photon Clouds directly in the shader menu.

Selected Photon Features

Carefully integrated Photon features sit alongside changes developed specifically for Reforged.

Physics Mod Support

Designed to work with the Physics Mod. Distant Horizons support is planned for a future update.

Get started

Up and running in a few steps.

Use the included patcher to build your Reforged shader pack from the required shader files. Original ZIPs are supplied by you, not redistributed here.

Before you start

Install OptiFine HD U G5+ or Iris, then obtain the required shader files from their respective official sources.

Download Reforged
01

Download Reforged

Get the latest release from the GitHub Releases page and extract the ZIP.

02

Get the required shader files

Download SEUS PTGI HRR 2.1, Bliss v2.1.2, and Photon v1.3b from their respective official sources.

03

Run Apply Patch

For the simplest method, double-click Apply Patch.bat. You can also drag the original SEUS and Photon ZIP files onto it.

04

Let the patcher do the work

The patcher searches for required files, verifies them, and generates your Reforged shader pack. Press Enter when prompted.

05

Enable the shader in Minecraft

Place the generated ZIP in your shaderpacks folder if not installed automatically, then select it in settings.
