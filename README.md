# About

SEUS PTGI HRR 2.1 Reforged is a community-made edit of **Sonic Ether's SEUS PTGI HRR 2.1**, focused on improving image quality and performance, adding more options for further configuration, fixing graphical issues, adding [Distant Horizons](https://modrinth.com/mod/distanthorizons) support, and bringing in select features from **Photon**, **Bliss** and **GFME** alongside original features developed specifically for Reforged!

Reforged is built around the original SEUS PTGI HRR 2.1 shader. The original shader provides the foundation alongside selected features from other shaders combined with my own features and improvements added on top of it. **The original SEUS and Photon shader files are not redistributed by the patcher. You provide the required files yourself, and the patcher only works with the copies on your system.**

> [!NOTE]
> SEUS PTGI HRR 2.1 Reforged is an **unofficial community edit!** It is not affiliated with or endorsed by Sonic Ether.

# Installation

### Windows

1. Install **[OptiFine HD U G5+](https://optifine.net/home)** or **[Iris](https://modrinth.com/mod/iris) + [Sodium](https://modrinth.com/mod/sodium)**.
2. Download the **SEUS PTGI HRR 2.1 Reforged** from [this repository](https://github.com/ThomasDeStrooper/SEUS_PTGI_HRR_REFORGED/releases?utm).
3. Download the original **SEUS PTGI HRR 2.1** from [Cody's Patreon](https://www.patreon.com/file?h=45141775&m=88959035).
4. Extract the **SEUS PTGI HRR 2.1 Reforged** ZIP to a suitable location of your choosing.
5. Once you have downloaded the required shader files, you can **double-click `Apply Patch.bat`** or manually dragging the shaders onto it.
6. The patcher will automatically search for the **SEUS PTGI HRR 2.1**, **Bliss** and **Photon v1.3b** shader ZIPs in common locations, such as your **Downloads folder and Desktop**.
7. If the patcher finds both shaders, it will automatically use them to generate your final **SEUS PTGI HRR 2.1 Reforged** shader pack.
8. The patcher will then ask whether you want to automatically install the generated shader into your shaderpacks folder. Enter **Y** for Yes or **N** for No. You can also simply **press Enter** to use the default option and automatically add the generated shader to your shaderpacks folder.
9. If the patcher cannot find one or both shader files, make sure the filenames are correct and place them somewhere the patcher can find them, then run **`Apply Patch.bat`** again.

### Linux
1. Install **[OptiFine HD U G5+](https://optifine.net/home)** or **[Iris](https://modrinth.com/mod/iris) + [Sodium](https://modrinth.com/mod/sodium)**.
2. Download the **SEUS PTGI HRR 2.1 Reforged** from [this repository](https://github.com/ThomasDeStrooper/SEUS_PTGI_HRR_REFORGED/releases?utm).
3. Download the original **SEUS PTGI HRR Test 2.1** from [Cody's Patreon](https://www.patreon.com/file?h=45141775&m=88959035).
4. Download Bliss, Photon 1.3b.
5. Extract **SEUS PTGI HRR 2.1 Reforged** into a folder of your choosing.
6. Place the shader files into the folder where you extracted the patcher.
7. Run `apply_patch.sh` by either running the terminal commands `cd PATH-TO-FOLDER` -> `./apply_patch.sh` and wait a few seconds. 
8. Place the newly generated **SEUS PTGI HRR 2.1 Reforged**.zip into your `shaderpacks` folder manually.

# Requirements

## Minecraft

* Minecraft **1.16.4 or newer**
* **OptiFine HD U G5+** or **Iris**

## Hardware

| Component       | Recommendation                        |
| --------------- | ------------------------------------- |
| Minimum GPU     | NVIDIA RTX 2050 / AMD Radeon RX 6500M |
| Recommended GPU | NVIDIA RTX 3060 / AMD Radeon RX 6700  |

These are general recommendations rather than strict requirements. Actual performance depends on resolution, Minecraft settings, view distance, shader settings, and the rest of your computer's hardware.

# Known Issues

## General

* Light rays can sometimes shine through buildings or other geometry, especially when using resource packs that feature 3D block models.

## NVIDIA

NVIDIA and AMD GPUs are currently the main tested hardware for Reforged.

## AMD

Some visual issues or occasional crashes may occur.

A possible workaround is to start Minecraft, or enable shaders, while the game is in a small window before switching back to fullscreen.

## Intel

Intel GPU compatibility is currently not guaranteed.

## Linux

Linux may experience unique issues not experienced by Windows users, but these will eventually be fixed.
